# ml-method-reports Documentation

`ml-method-reports` is an educational Python toolkit for interactive exploration, explanation, visualization, and reporting of machine learning methods.

It exists because learners often see only final model metrics. The toolkit helps expose the intermediate artifacts that make a method understandable: distances, prototypes, neighbors, votes, rules, coefficients, support vectors, cluster centers, errors, and metrics.
