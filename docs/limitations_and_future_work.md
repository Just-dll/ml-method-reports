# Limitations and Future Work

## Limitations

- sklearn-based models are not manually reimplemented.
- Explanation depth depends on available model artifacts and provided train/test data.
- PDF output is less interactive than notebook and HTML output.
- Some visualizations are intentionally educational summaries rather than production monitoring dashboards.

## Future Work

- Neuro-fuzzy model reports.
- Richer model comparison criteria.
- Interactive dashboards.
- Automatic notebook export.
- Widgets for selected sample exploration.
