# Examples

Example scripts live in `examples/`.

Run one report:

```bash
python examples/knn_classification_report.py
python examples/logistic_regression_report.py
python examples/decision_tree_report.py
python examples/random_forest_report.py
python examples/svc_report.py
python examples/kmeans_report.py
python examples/agglomerative_report.py
```

Generate the full demo catalog:

```bash
python examples/generate_all_reports.py
```

Outputs are written to `runtime/reports/`.
